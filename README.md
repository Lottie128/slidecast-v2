# SlideCast V2

AI-Powered Video Presentation Platform

## Setup

```bash
# Install dependencies
bun install

# Run dev servers
bun run dev:client  # Frontend on :5173
bun run dev:server  # Backend on :3000
```

## Tech Stack

- React + TypeScript
- Tailwind CSS v4
- Vite
- Bun runtime
- PostgreSQL
